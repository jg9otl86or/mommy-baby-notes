# fsh高lh低是不是早衰？lh除以fsh大于2一定是多囊？

> 更新时间：2026-09-19 (UTC+8)

fsh高lh低是不是早衰？那本文就这个问题以lh除以fsh大于2一定是多囊为大家详细介绍一下。

**fsh高lh低是不是早衰**

激素六项检查结果显示fsh高lh低不一定就是早衰，fsh高且fsh与lh比值大于3考虑多囊卵巢综合症的可能，多囊卵巢综合症会导致fsh升高,lh降低的情况。同时早衰的情况一般是fsh升高，lh同时也升高，且两者均在20以上的情况下。fsh与lh是随时都在变化的，fsh与lh的比值在不同时期测也会有不同的结果，所以建议多测几次，同时最好在月经第3-5天空腹抽血测最好。

如果发现fsh与lh的值明显偏高，且都大于20，应该立即引起注意，去医院做个B超和内分泌检查，以确定早衰的程度和具体情况，以准确诊断对症下药。不能仅凭FSH，LH这些指标去判断是否卵巢早衰，卵巢早衰的诊断标准如下：

1. 年龄在40岁以下，月经稀发或超过4个月没有来月经；

2. 至少两次不同日的血清FSH25IU/L且间隔4周或FSH40IU/L；

3. 伴有潮热、汗出、阴道干涩、头晕、情绪波动、失眠及性欲减退等更年期症状。

fsh/lh是指卵泡生成激素与黄体生成激素的比值，两者一般都是在5-10IU/L，而比值应该在1左右，但现实生活中女性体内这两种激素合理的比例应该是1：1.5。

早衰是女性的一大杀手锏，不仅影响女性的健康生活，还影响女性内分泌激素，导致生理心理双重的打击，所以，平时一定要多注意锻炼，养成良好的生活习惯，避免出现早衰的现象。

**lh除以fsh大于2一定是多囊**

激素六项报告单的lh值除以fsh值大于2不一定就是多囊，但确实要考虑存在多囊卵巢综合症的可能。因为lh、fsh分别表示促黄体生成激素和促卵泡生成激素，如果这两个数值出现增高，那么女性就会出现不排卵和月经紊乱症状，这就可以初步诊断为多囊。具体还需要结合多囊的症状、B超卵巢样来综合诊断才行。

多囊卵巢是一种内分泌的紊乱和代谢异常的一种疾病，其临床表现是较为复杂的，患者可能是胖的也可能是瘦的，会出现多毛、痤疮、月经紊乱、不孕等症状。目前临床上要诊断多囊卵巢的方法具体如下：

1. 月经多年不规律、月经稀少或闭经，患者出现40天以上才来一次月经，同时排卵监测无卵泡，就可以诊断稀发排卵或者是不排卵；

2. 做b超检查，提示患者的两侧卵巢出现了多囊状改变，两侧卵巢内2-9mm的卵泡数≥12个，和（或）卵巢体积≥10mL；

3. 激素六项报告单提示fsh值正常或偏低，lh值明显升高，且lh值除以fsh值在2-3之间；

4. 患者出现高雄激素血症，例如出现毛发增多、脸上痤疮、肾上腺皮质增生等。

以上就是临床上诊断多囊卵巢的标准，符合大部分的情况，那么就可以诊断为多囊。而激素六项报告单lh值除以fsh值大于2只能作为初步诊断结果，具体是不是多囊，还需要做进一步的检查了解才能明确。如果确诊了多囊卵巢，就需要考虑通过短效避孕药+运动+饮食来治疗，已帮助控制病情。
