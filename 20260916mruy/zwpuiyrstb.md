# 郑大三附院生殖中心文献荟萃第168期---口服避孕药的类型和使用时间对IVF/ICSI周期的活产和累计活产率的影响

> 更新时间：2026-09-16 (UTC+8)

**研究问题：**与没有使用过口服避孕药（OCP）的女性相比，在接受不同类型口服避孕药（OCP）进行不同持续时间预处理的控制性促排卵IVF/ICSI患者，其新鲜周期活产率（LB）和累积活产率（CLBR）是否有差异？

**总结：**控制性促排卵IVF/ICSI周期患者，OCP预处理时间为12至30天，停药5天后开始COS，不会影响临床妊娠、活产或累积活产率。

**已知信息：**IVF/ICSI周期中使用OCP预处理是一种有效治疗方法，但在已发表的有关研究中其对妊娠和活产率的影响不一致，一些研究发现其活产率降低，但其他研究没有发现差异。

**研究设计，规模，时间：**这是一项于2009年1月至2017年12月在大学附属大学三级生殖中心进行的回顾性分析。总体而言，我们纳入了4116名在我们中心进行第一次促排卵的18至45岁的不孕妇女。

**参与者/材料，背景，方法：**将患者分为接受OCP（n = 3517）或未接受OCP（无OCP，n = 599）的两组。所有接受OCP预处理的患者在停药5天后均开始促排卵治疗（COS）。研究中心使用了两种类型的OCP：乙炔雌二醇（EE）30μg/去氧孕烯150μg，第三代孕激素；或乙炔雌二醇30μg /屈螺酮3mg，具有轻度抗雄激素活性的第四代孕激素。

**主要结果及偶然性的作用**：我们分析了总共4116名患者（OCP 组，n = 3517和无OCP组， n = 599）。在对年龄，BMI，OCP的使用，不孕原因，启动剂量（IU），促性腺激素的类型，促排天数，Gn总量进行调整后，OCP的使用与获得的卵母细胞数量的小幅增加独立相关。（β0.22，95％CI 0.12-0.31）。OCP组与非OCP组之间的累积活产率相当（32.4％：31.6％，P = 0.712）。在使用多因素逻辑分析调整年龄，BMI，不育类型，Gn起始剂量和总剂量，促性腺激素的类型，用药总天数，授精的类型，获卵数，移植胚胎类型和移植胚胎数后，在移植鲜胚的患者中，使用OCP的患者与不使用OCP的患者相比，活产率类似（ORadj 0.89，95％CI 0.69-1.15），使用新鲜和冷冻胚胎后CLBR的类似（ORadj 0.94，95％CI 0.73-1.21）。屈螺酮和去氧孕烯酸OCP组间在卵巢刺激和临床结局方面均未观察到差异。

**局限性，注意事项：**局限性与研究的回顾性有关。除外样本量，采用调整和多元回归分析后，我们不能排除存在混杂偏倚的情况；没有随机分配OCP给药，不允许排除选择偏倚的存在；最后，根据课题要求，我们仅使用两种类型的OCP，其作用持续时间和清除期有限。因此，我们不能排除更长的药物作用时间，不同类型的OCP或不同的用药间隔可能会对LBR或CLBR产生替代性影响。因此，应谨慎考虑本研究结果的普遍性。

**研究结果更广泛的意义：**我们的研究提供了令人放心的证据，即在IVF/ICSI之前使用12-30天的OCP进行预处理不会降低活产的机会和累计活产率。
