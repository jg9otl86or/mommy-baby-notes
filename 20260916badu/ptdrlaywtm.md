# 乳腺巨大肿瘤超20cm！多学科团队“巧施妙计”让患者重获新生

> 更新时间：2026-09-16 (UTC+8)

乳腺癌位列全球女性恶性肿瘤第一位，发病率高，尤其是三阴型乳腺癌，目前可用的全身治疗手段有限，一旦进入晚期，治疗就会相当棘手，甚至部分患者可能会因为肿瘤破溃出血导致身体状况每况愈下。

近日，中山大学附属第一医院乳腺外科就接诊了一位巨大乳腺恶性肿瘤合并破溃出血的患者，她因全身治疗效果不佳，肿瘤不断生长，破溃出血，因手术难度极大，辗转求助多家医院无果。

在中山一院乳腺疾病多学科团队保驾护航下，乳腺外科张赟建副主任联合烧伤与创面修复科唐锦明医生成功为该患者实施了乳房巨大肿瘤切除及延期复合皮移植手术。术后患者恢复良好，已顺利出院。

▲乳腺外科林颖主任、张赟建副主任和唐锦明医生成功救治患者

**乳腺巨大肿瘤超过20cm**

**尝试多种治疗方案仍未奏效**

54岁的邓女士10余年前发现左乳肿物，伴有疼痛及乳头溢液，当时未予重视。9个月前在广州某医院就诊，经活检确诊为乳腺浸润性癌，三阴型。影像学检查提示肿瘤巨大、血供丰富，边界不清，肿瘤累及同侧胸壁并伴有多处淋巴结转移及双肺转移。

尽管外院给予了标准的一线治疗，但是不幸的是，肿瘤对这些治疗的疗效不佳，很快，邓女士就先后经历了3种不同方案的姑息治疗，甚至还用上了目前最新的抗体偶联药物，仍然没有得到很好的控制。

经历了化疗、免疫治疗、靶向治疗之后的肿瘤不但没有退缩，而且还在继续生长，以至于局部破溃出血，患者生活质量受到严重影响，甚至无法直立行走，来到中山一院就诊时，她胸前的巨大肿瘤已超过20cm，累及整个左胸前区皮肤。

▲患者胸前的巨大肿瘤已超过20cm

虽然多线姑息治疗效果欠佳，但患者还是希望能够通过手术来切除胸前这个巨大的肿块。此时的她除了肿瘤状况以外，还伴有严重的贫血表现，血红蛋白最低达49g/L，红细胞只有1.89 X 10^12/L，出现了低白蛋白血症等消耗性改变。

接诊的张赟建副主任表示，邓女士的手术时机稍瞬即逝，如果不能把患者的一般状态调整好，创造手术机会，她将可能很快进入到疾病的终末期，危及生命。

****

**多学科团队讨论救治方案**

**分期手术助患者渡过难关**

中山一院乳腺外科MDT团队，包括乳腺外科、医学影像科、肿瘤内科、麻醉科、放射治疗科等专家仔细分析该患者病情后，认真讨论，医生团队一致认为手术还是可以给这名晚期患者带来生活质量的改善，于是，乳腺外科当机立断提出联合烧伤与创面修复科实施多学科手术，林颖主任和烧伤与创面修复科谢举临主任详细制定了手术方案。

将患者收入院后，术前，医生团队对患者进行了抗感染、营养支持、纠正贫血及低蛋白血症等治疗，经过数天的对症支持治疗，患者的感染及贫血情况较前明显好转。经和患者及家属沟通后，最终决定为患者实施手术治疗。

由于该患者肿瘤直径较大，腋窝淋巴结转移并紧邻重要的血管及神经，且癌灶伴有严重感染，切除肿瘤后，需要考虑到胸部皮肤缺损的修复。另外，患者一般身体状况较差，不能耐受长时间的大手术，于是，专家团队决定分期处理病情，首先由乳腺外科将巨大肿瘤切除，然后烧伤与创面修复科先通过VSD负压吸引的方法覆盖创面，待炎症控制，创面长出足以维持植皮的肉芽组织后，再进行延期植皮修复创面。

“这样一来，既能将单次手术创伤降到最低，同时又可以达到手术治疗效果，提高植皮成功率，为后期的全身治疗带来更多的机会。”张赟建副主任说道。

▲张赟建副主任与唐锦明医生实施手术

手术由乳腺外科张赟建副主任、烧伤与创面修复科唐锦明医生具体实施，麻醉科冯霞主任、手术室龚凤球护长协同。

手术台上，肿瘤与术前评估一致，直径超过20cm，表面多处破溃，伴渗血及脓性分泌物。由于肿瘤与胸大肌、胸小肌紧密黏连，肿瘤内部感染和坏死，肿瘤周围血管增生，导致操作难度大，术中出血风险高。所幸，整个团队配合默契，将肿瘤连同胸大肌、部分胸小肌一起整体切除，最后利用负压引流装置封闭创面。

仅在3个小时内，张赟建副主任和唐锦明医生及手术团队便完成了一期手术，术后患者生命平稳，渡过了第一关。

**胸部巨大肿瘤切除后**

**患者如重获新生**

在回到普通病房后，烧伤与创面修复团队为患者提供了手术创面的精细护理、数次溃疡修复术以及抗感染、补液、改善营养等对症支持治疗。患者的各项血常规指标迅速好转，血红蛋白在未输血下已回升至91g/L，红细胞达到3.1 X 10^12/L。

术后，患者的精神状态也有了明显好转，从原来不能直立行走奄奄一息，到已经能在病区内自由散步，她的脸上也露出了已久的笑容和自信。“胸部的巨大肿瘤被切除以后，我整个人就如同重获新生一般。”

在一期手术后的10天，医生团队给患者换药评估，考虑创面肉芽生长满意，可以进行二期手术“胸壁慢性溃疡修复术+头皮取皮术+胸壁游离皮片移植术”治疗。二期手术后一周，患者的伤口植皮成活，术后恢复顺利，已于7月底康复出院。出院前，患者及家属对中山一院的医疗救治团队表示深切感谢，并要求后期治疗继续留在我院进行。

▲正在康复的乳腺癌患者

张赟建副主任表示，此例乳腺巨大肿瘤的成功救治离不开各兄弟科室的紧密合作和MDT团队成员的相互支持，是多学科团队通力协作的成果，充分体现了中山一院外科团队果敢担当的精神和精湛的手术技艺，再次展现了医院对疑难复杂病例的强大综合实力。同时医疗团队的医者仁心也给予了患者治疗的信心和勇气。“只有在医生和患者相互信任的基础之下，才能为患者带来最好的治疗效果。”
